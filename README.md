# 宝藏资源库 · Treasure Resource Library

把网站、工具和应用整理成可持续维护的本地 Markdown 资源表。

这是一个 Agent Skill：由支持 `SKILL.md` 的智能体执行资料检索、核验和截图，配套 Python 脚本负责可靠更新表格与下载媒体。它不是独立的搜索引擎或后台采集服务。

## 功能

- 接收一个或多个网站名称、网址、App 或桌面软件名称。
- 交叉检索官方介绍、独立评测和用户反馈；介绍不超过 200 字，单句评价不超过 150 字。
- 生成十列表格：名称、官方网址、介绍、评价、类型、五个标签、下载方式、多媒体资料、更新时间、备注。
- 官网无法核验时仍保留实际找到的地址，在备注明确写“网址未验证”及原因；不编造域名。
- 官方图片、视频优先本地保存；下载失败时尝试保存首页及关键功能页合计 1～3 张截图，截图也不可用时保留可核验的来源链接。
- 每次任务确认保存路径；本次已提供路径则直接使用。
- 新资源追加，重复且有实质变化更新原行，无变化不写入。保留无关文档内容和用户备注。
- 只生成表格，不添加资源库标题；保留必要的隐藏维护标记及表格前后空行。
- 兼容旧九列表格，升级时增加空备注列并保留原有时间。

## 安装

将本仓库克隆或解压到 Codex 个人技能目录下的 `treasure-resource-library` 文件夹，确保布局如下：

```text
~/.codex/skills/treasure-resource-library/SKILL.md
```

如果设置了 `CODEX_HOME`，使用该目录下的 `skills/treasure-resource-library`。保留 `agents/`、`references/`、`scripts/` 目录。其他支持 Agent Skills 的客户端请按各自方式安装，并确认其具备所需工具。

## 使用示例

```text
请使用 $treasure-resource-library 整理 Notion、Obsidian 和 https://reactbits.dev/，
保存到我指定的资源目录。
```

提供文件夹时创建或维护 `宝藏资源库.md`；提供 Markdown 文件时维护其中的资源库区域。普通文档末尾追加表格，不替换原文。

## 运行要求

- 支持此技能格式的智能体，以及网络搜索和网页读取工具。
- Python 3.10+：两个辅助脚本只使用标准库。
- 本地截图需要浏览器或应用截图工具支持导出图片；没有这些能力时会记录原因，不能保证所有页面都能截图。
- 本地媒体放在文档旁的 `<文档名>_素材/<资源标识>/`，与文档一起移动，以保持相对路径有效。

Obsidian 请使用实时预览或阅读视图查看排版；源码模式显示竖线与隐藏标记属于正常现象。核验只反映采集当时的状态，搜索与截图质量取决于可用工具及网站访问条件。

## 脚本与验证

脚本接口见 [存储说明](references/storage.md)，完整执行规范见 [SKILL.md](SKILL.md)。`media.py` 只负责直接媒体下载，截图由智能体调用环境工具完成。

```bash
python -m unittest discover -s tests -v
```

测试覆盖追加与更新、无变化不写入、原文保护、旧格式迁移、备注、字符转义、并发冲突及模拟媒体下载。模拟下载测试不代表已验证真实网站或应用界面。
