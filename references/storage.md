# 表格维护接口

使用 Python 3.10+，脚本路径相对于技能目录；可将 `python` 替换为环境中的绝对路径。

## 检查

`python scripts/library.py inspect --path "用户路径"`

返回目标 Markdown 路径、SHA-256 版本（新文件为 `missing`）及既有记录。文件夹自动定位 `宝藏资源库.md`。支持 UTF-8 和 UTF-8 BOM，其他编码停止处理，不转换原文。

## 更新

在任务临时目录准备 UTF-8 JSON：

```json
{
  "expected_sha256": "inspect 返回的值",
  "utc_offset": "+08:00",
  "records": [{
    "identity": "official:https://example.com/product",
    "name": "示例产品",
    "url": "https://example.com/product",
    "intro": "经官方资料核实的介绍。",
    "review": "独立用户评价不足，暂无法形成可靠口碑结论。",
    "type": "网站",
    "tags": ["写作", "协作", "文档", "办公", "知识管理"],
    "download": "在线使用，无需下载",
    "media": "",
    "notes": ""
  }]
}
```

`python scripts/library.py update --path "用户路径" --input "临时 JSON 路径"`

输出新增、更新、未变化数量。`url` 是实际找到或由用户提供的官方网址裸 URL，即使无法核验也填写，同时在 `notes` 中注明“网址未验证”并补充实际原因；官方归属也不确定时明确说明。只有完全没有地址时才用空字符串，不能编造域名。脚本仅检查 HTTP(S) URL 格式，不代表已经联网验证；整理者负责判断核验状态并填写备注。后续验证成功时更新对应备注，保留其他异常与用户内容。下载和媒体可以包含 Markdown 链接，用真实换行分隔，脚本转为 `<br>`。介绍与评价用纯文本。竖线由脚本转义；链接目标中的竖线需预先编码成 `%7C`。

identity 优先采用 `official:<规范官方产品URL>` 或 `app:<商店>:<产品ID>`。规范化可统一主机大小写、移除经确认的跟踪参数和无意义末尾斜杠，不删除有身份意义的路径或参数。多种地址先用官方跳转、开发者等证据确认；无可靠身份先澄清，不按名称拼 identity。

已有资源复用检查返回的 identity。更新可只提交 identity 和确实变化的字段；省略字段保留，显式空字符串会清空，因此不能以空值覆盖暂时未知字段。标签换序不更新。脚本自行生成更新时间。

库区用 `<!-- treasure-resource-library:v1:start -->` 和 `<!-- treasure-resource-library:v1:end -->` 标记，行中包含编码 identity。只接受固定表头、合法记录和空行；未知版本或结构异常拒绝修改。不能去掉标记绕过拒绝。无任何技能标记的普通文档仅末尾追加。

独占锁、版本比较、写入前复核和原子替换降低并发风险；外部编辑器不遵守锁时，最终仍有极短竞争窗口，不能声称系统级事务保障。锁已存在时不自动删除，先确认其他写入任务状态。

## 表格显示修复

表格与前后的 HTML 隐藏标记之间必须各留一个空行，表头、分隔行和所有资源行之间不能插入空行，每条记录占一个物理行，格内换行使用 `<br>`。普通更新无实质变化时仍不写入。

用户明确要求修复旧文档显示时，先 inspect，再提交 `{"expected_sha256":"读取版本","records":[],"repair_format":true}`。只补齐缺失的分隔空行，不改资源内容或更新时间；再次执行应完全不写入。修复后用支持 GFM 表格的渲染器确认生成一个十列表格，不仅检查源文本。

## 媒体下载

`python scripts/media.py --url "已验证的直接媒体URL" --directory "文档旁素材目录/资源ID"`

返回本地路径、哈希及是否复用。按内容哈希命名，支持 JPEG、PNG、GIF、WebP、MP4、WebM，拒绝 HTML 错误页。默认单文件上限 512 MiB，可用 `--max-mb` 调整。脚本不能证明产品归属或真实性，须先人工核实。下载后确认可打开；失败时按 SKILL.md 的截图流程，优先保存该资源首页与关键功能页合计 1～3 张截图。截图也不能保存时才退回已核验的来源页，异常和处理结果写入 `notes`。

截图由当前可用的浏览器或应用截图工具产生，`media.py` 本身不提供截图功能。本地截图仍通过 `media` 字段中的 Markdown 相对路径图片引用，无需新增表格列或修改脚本输入格式。写入前必须核实文件真实存在、可打开，不能把工具会话中的临时图片地址当作持久路径。

## 十列格式与旧版兼容

新增 `notes` 字符串，对应最后一列“备注”。新记录省略时默认为空；更新省略则保留既有备注，显式空字符串会清空，必须先保留用户手写内容及尚未解决的异常。换行和竖线会转义。

新建或追加库区不生成标题。旧九列表格更新时自动迁移，旧字段与时间保持原样，仅新增空备注格；返回 `schema_migrated`。只在库区前的全部内容恰好为旧生成标题与空行时移除标题（`title_removed`），否则保护原文。可用空 records 数组单独迁移；无变化不写入的规则在迁移完成后保持有效。隐藏容器标记仍为 v1，解析器严格接受旧九列表头或新十列表头，其他结构拒绝修改。
